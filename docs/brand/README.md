# Logos

All logo files are outlined SVG (no live text). Single-ink files are named by ink: no suffix = `black` (#0e0e0c), `-white` = `white`. Avatars carry their own ground.

- `roleback-lockup` — the default Roleback logo, for the product and company pages alike. `roleback-symbol` — the Turn, app icon and ≤32px. `roleback-wordmark` — when the symbol is already nearby.
- `tracecart-lockup`, `tracecart-wordmark`, `tracecart-symbol` (the Trace) — Tracecart. `tracecart-endorsed` — with "a roleback company", for footers, decks and contracts.
- `roleback-favicon`, `tracecart-favicon` — 16–48px cuts (smaller counter / heavier route).
- `roleback-avatar` (black on orange), `roleback-avatar-black` (orange on black), `roleback-avatar-yellow` (black on yellow, company channels), `tracecart-avatar` (black on green) — social and app avatars; crop to a circle.

Wordmarks: Roleback in Bricolage Grotesque 800, opsz 96, wdth 88, −2% tracking; Tracecart in Bricolage Grotesque 720, opsz 96, wdth 100, −1% tracking. Both lowercase.

Clear space: half the symbol's width. Minimum: symbol 16px, lockup 72px wide. Only black, white, or black on an accent ground.
